1. 수집하는 개인정보 항목

1-1. 회원가입 / 로그인

  • 필수: 이메일 주소, 비밀번호 해시
  • 선택: 표시 이름

1-2. 서비스 이용 과정에서 수집

  • 통화 메타데이터: 통화 일시, 통화 시간(초), 상대방 전화번호
  • 통화녹음 파일: 사용자 단말이 보유한 통화녹음 파일 중 사용자가 "양식으로 전송" 또는 "요약보기" 를 누른 통화에 한해 일시 수집
  • 통화 요약 결과: AI(Whisper STT + Claude LLM) 가 생성한 통화 요약 텍스트
  • 사용자가 직접 입력한 고객관리대장 메모
  • 결제 정보: Google Play 결제 시스템을 통해 처리되며 회사는 카드번호를 직접 수집·저장하지 않음

1-3. 자동 수집

  • 디바이스 식별자 (FCM 토큰)
  • 앱 사용 로그 (오류 로그, 처리 시각)
  • IP 주소

1-4. 단말기 권한 접근

  • 전화 상태(READ_PHONE_STATE): 통화 시작/종료 시점을 감지하여 모달 표시 시점 결정
  • 미디어 오디오(READ_MEDIA_AUDIO): 다른 앱(T전화 등)이 저장한 통화녹음 파일을 사용자 동의 후 읽기
  • 알림 표시(POST_NOTIFICATIONS): 처리 진행 안내
  • 잠금화면 모달(USE_FULL_SCREEN_INTENT): 통화 종료 시 잠금화면 위에서 한 번에 저장 가능하도록 표시
  • 배터리 최적화 예외(REQUEST_IGNORE_BATTERY_OPTIMIZATIONS): 통화 종료 직후 핵심 흐름이 중단되지 않도록 사용자 동의 후 요청
  • 발신번호 표시(CallScreening Role): 통화 시작 전 고객관리대장과 매칭한 정보 표시 (차단·스팸 기능 없음)

영맨은 폰 주소록, 카메라, 사진·동영상, 다른 앱 위에 그리기 권한을 사용하지 않습니다.
