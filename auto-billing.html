영맨 자동결제 안내

시행일: 2026-05-21

사업자: 어센트라(Ascentra)

1. 자동결제란

영맨 Sales/Master/Agency 구독은 회원이 별도로 해지하지 않는 한 매월 동일한 결제일에 자동으로 결제됩니다.

2. 결제 처리

  • 결제 처리: Google Play 결제 시스템
  • 회사는 카드번호·CVC 등 결제 수단 정보를 직접 보관하지 않습니다.
  • 결제 시도 후 결제 결과(성공/실패)는 사용자에게 알림으로 전달됩니다.

3. 결제 실패 시

  • 카드 만료, 한도 초과 등으로 결제 실패 시 영맨이 알림 발송
  • 3회 결제 실패 시 자동으로 구독이 일시 정지(past_due)
  • 결제 정보 갱신 후 자동 재시도

4. 해지 방법

  • 앱: 설정 → 내 플랜 / 구독 관리 → 구독 해지
  • 웹: youngman-biz.com → 마이페이지 → 구독 해지
  • 해지 시 현재 결제 주기 종료일까지 서비스 이용 가능, 다음 주기 결제 안 함

5. 결제 변경

  • 결제 수단 변경: youngman-biz.com → 마이페이지 → 결제 수단 관리
  • 플랜 변경(Sales ↔ Master ↔ Agency): 마이페이지 → 플랜 변경 (다음 결제일부터 적용)
